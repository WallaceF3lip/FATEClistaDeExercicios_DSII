Fundamentos da Web

Páginas estáticas, dinâmicas e como o navegador conversa com o servidor

Página Estática

É o tipo mais simples de página. O arquivo HTML já tá pronto no servidor e é entregue ao navegador exatamente do jeito que está, sem nenhum processamento. O conteúdo não muda entre uma visita e outra.

Exemplo real: Um portfólio pessoal no GitHub Pages — texto, foto e links fixos que só mudam se o dev editar o HTML na mão.

Página Dinâmica

O conteúdo é gerado na hora, quando chega a requisição. O servidor roda uma lógica (lê o banco de dados, verifica quem tá logado, etc.) e só depois monta e devolve o HTML pro navegador.

Exemplo real: O perfil do Instagram — cada usuário vê suas próprias fotos e seguidores porque o servidor consulta o banco de dados e monta o HTML com os dados específicos daquele perfil.

Como funciona o caminho entre navegador, servidor e resposta

  1. O usuário digita uma URL no navegador e pressiona Enter.
  2. O navegador envia uma requisição HTTP pro servidor.
  3. O servidor recebe a requisição e localiza o recurso pedido.
  4. Se precisar, executa uma lógica no back-end (código, consulta ao banco de dados).
  5. Monta a resposta HTTP com o conteúdo (HTML, imagem, JSON, etc.).
  6. O navegador recebe a resposta e renderiza a página pra quem pediu.
